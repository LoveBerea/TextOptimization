## 产品概述

酒馆助手文本优化脚本，通过 AI 对聊天楼层中正则匹配的文本进行优化润色，提供原文与优化文本的对比界面，确认后自动替换楼层内容。

## 核心功能

- **文本优化**：通过 `getChatMessages` 获取指定楼层消息，用可配置正则匹配提取文本，调用 AI 优化后展示对比结果
- **配置管理**：配置 AI 接口（openai兼容/deepseek/gemini/kimi四种格式）、正则表达式、优化提示词，最多保存3种配置方案并切换
- **对比界面**：左右分栏显示原文与优化后文本，支持逐行对比
- **确认替换**：点击确认后，将优化文本替换楼层消息中正则匹配的部分，通过 `setChatMessages` 写回
- **四个脚本按钮**：优化、配置、确认、取消

## 技术栈

- 语言：TypeScript + Vue 3（组合式 API）+ Pinia + Zod
- 样式：`<style scoped>` + 酒馆原生 CSS 类（禁止 tailwind，因组件挂载在酒馆页面 DOM 上）
- 构建：项目现有 webpack 配置，脚本放在 `src/文本优化/` 下自动被扫描打包
- 数据持久化：脚本变量 `getVariables/insertOrAssignVariables({type: 'script', script_id})`
- AI 调用：`generateRaw({custom_api, ordered_prompts})` 自定义 API 调用

## 实现方案

### 整体架构

脚本以无沙盒 iframe 形式运行，通过 jQuery 操纵酒馆页面。配置面板与对比界面均作为 Vue 组件，通过 `createScriptIdDiv` 挂载到酒馆页面 DOM 上，使用 `teleportStyle` 复制样式。

### 核心数据流

```
用户点击"优化"按钮
→ getChatMessages(楼层号) 获取楼层 message
→ 正则匹配提取待优化文本片段
→ generateRaw({custom_api, ordered_prompts}) 调用 AI
→ 对比界面展示 原文 vs 优化文本
→ 用户点击"确认" → 替换原 message 中匹配部分 → setChatMessages 写回
```

### AI 格式与 source 映射

| 用户选择 | CustomApiConfig.source | 说明 |
| --- | --- | --- |
| OpenAI兼容 | `'openai'` | 通用 OpenAI 格式 |
| DeepSeek | `'openai'` | DeepSeek 兼容 OpenAI 格式 |
| Gemini | `'google'` | Google 原生格式 |
| Kimi | `'openai'` | Kimi 兼容 OpenAI 格式 |


选择格式时自动填充对应 apiurl 模板（如 deepseek 填 `https://api.deepseek.com/v1/chat/completions`），用户可修改。

### 配置持久化

使用 zod 定义配置 schema，pinia store 管理响应式状态，`watchEffect` 自动同步到脚本变量。最多3种配置以数组存储，`active_config` 索引标记当前使用的配置。

### 对比界面挂载策略

- 使用 `createScriptIdDiv()` 创建容器，`appendTo('body')` 作为浮层
- `teleportStyle()` 复制样式到酒馆页面 `<head>`
- 组件内使用 scoped CSS 实现模态框样式
- 禁止 tailwindcss（避免与酒馆页面类名冲突）

### 关键模块说明

**index.ts** - 主入口

- `$(() => {...})` 中初始化：注册4个脚本按钮（优化/配置/确认/取消），挂载配置面板到 `#extensions_settings2`（默认折叠），挂载对比界面到 `body`（默认隐藏）
- 按钮事件：优化→调用 optimizer 逻辑；配置→切换配置面板显示；确认→执行替换；取消→关闭对比
- `pagehide` 时卸载所有组件和样式

**settings.ts** - 配置管理

- `AIConfigSchema`：name, source, apiurl, key, model, regex, prompt
- `SettingsSchema`：`configs: z.array(AIConfigSchema).max(3)`, `active_config: z.number()`
- `useSettingsStore`：pinia store，从脚本变量读取/写入配置

**optimizer.ts** - 核心逻辑

- `extractText(message, regexStr)` → `{match, before, after}` 正则提取及上下文
- `optimizeText(text, aiConfig)` → 调用 `generateRaw` 返回优化文本
- `applyOptimization(messageId, original, optimized, regexStr)` → 替换后调用 `setChatMessages`

**配置界面.vue** - 配置面板

- 使用酒馆 `inline-drawer` 折叠样式（参考示例/脚本示例/设置界面.vue）
- 配置槽位选择（1/2/3），AI格式下拉（自动填充apiurl模板），API Key/Model输入，正则输入，提示词输入
- 保存按钮将配置写入 pinia store（自动同步到脚本变量）

**对比界面.vue** - 对比浮层

- 模态框样式浮层，半透明遮罩
- 左右分栏：原文 | 优化后文本
- 底部按钮栏：确认 / 取消
- 确认→调用 `applyOptimization` → `setChatMessages` → 关闭浮层
- 取消→关闭浮层

### 性能与边界

- AI 调用期间禁用优化/确认按钮，防止重复请求
- 正则匹配失败时 `toastr.warning` 提示，不发起 AI 请求
- API Key 等敏感信息仅存于酒馆脚本变量中，不输出到日志
- 配置变更通过 `watchEffect` 增量同步，非全量替换

## 设计方案

脚本包含两个 Vue 组件挂载到酒馆页面，需与酒馆原生视觉风格融合，同时对比界面需清晰突出。

### 配置面板

- 挂载位置：`#extensions_settings2`（酒馆扩展设置区域）
- 使用酒馆原生 `inline-drawer` 折叠面板样式，与酒馆其他扩展设置视觉一致
- 标题栏："文本优化" + 折叠箭头图标
- 内部布局：垂直表单，配置槽位标签页切换（1/2/3），各输入项使用酒馆 `menu_button` / `text_pole` 样式类
- 禁止 tailwindcss，使用 `<style scoped>` + 酒馆原生 CSS 类

### 对比界面

- 挂载位置：`body`，作为全屏模态浮层
- 遮罩层：半透明黑色背景 `rgba(0,0,0,0.5)`
- 对比卡片：居中弹窗，深色背景（与酒馆暗色主题一致），圆角，轻微阴影
- 左右分栏布局：左侧"原文"标签+文本区，右侧"优化后"标签+文本区，中间竖线分隔
- 底部操作栏：确认（绿色调）和取消（灰色调）按钮，使用酒馆 `menu_button` 样式
- 文本区域：等宽字体，可滚动，保持原始换行
- 楼层号显示在弹窗标题栏
